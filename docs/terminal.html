Kerstel Terminal

A secure terminal for your keys, on macOS and Linux. Your own shell with Kerstel built in, and your secrets one shortcut away: masked, encrypted, and never on a command line.

Built for secrets

Your keys, handled with care

Most terminals treat a secret like any other text. Kerstel Terminal's Kerstel panel knows which values are secrets, and keeps them out of the places they usually leak. What your own commands print still shows on screen, as in any terminal.

An encrypted vault, on your machine

Values are encrypted with AES-256-GCM, and the key that unlocks them is held by the macOS Keychain or Linux's Secret Service. No account, no cloud, no telemetry.

Masked until you ask

Every value shows as ••••••••. Showing or copying one takes a deliberate click, and each one is recorded in kerstel audit.

A clipboard that cleans up

A copied value is wiped from the clipboard after 30 seconds, unless you have copied something else since.

Never on a command line

A secret you add reaches kerstel set on stdin, never as an argument, so it stays out of process lists and shell history.

A panel with a short leash

The panel can run only an allowlisted set of kerstel commands. Setting up sync or adding a device runs in the terminal, where you see and answer every question.

Signed, notarized, checksummed

The macOS app is signed and notarized by Apple, and every download has a checksum in the release's SHA256SUMS. All of it is open source.

A real terminal

Nothing new to learn

It runs your own login shell, so your prompt, aliases, vim, ssh and everything else work as they do today. On top, it adds only what helps:

  • The current folder and git branch at the top of the window.
  • A hairline between commands, with each command's duration and a ✓ or ✕ with its exit code.
  • A row of key hints that lights up as you use them. Hide it once you know them.
  • A command palette (⌘K) with your recent commands. Picking one types it at the prompt; nothing runs until you press Enter.
Kerstel built in

Your secrets, one shortcut away

Press ⌘J (Ctrl+Shift+J on Linux) to open the Kerstel panel.

  • Secrets: filter, add, and delete. Values stay masked. Showing or copying one is recorded in kerstel audit, and a copied value is cleared from the clipboard after 30 seconds.
  • Sync: see the server, the last sync and your devices. Set up a server, join from another device, or add a device in a click. Each of these runs in the terminal, where Kerstel asks its usual questions. See Sync.
  • Doctor: check this machine's setup with one click.

The panel runs the same kerstel you use on the command line, so they always agree.
