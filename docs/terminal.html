Kerstel Terminal

A calm terminal for macOS and Linux, with Kerstel built in. Your own shell, a quiet line between commands, and your secrets one shortcut away.

Includes the kerstel CLI. On first launch it offers to install kerstel and ks for every terminal. Checksums are in each release's SHA256SUMS.

A real terminal

Nothing new to learn

It runs your own login shell, so your prompt, aliases, vim, ssh and everything else work as they do today. On top, it adds only what helps:

  • The current folder and git branch at the top of the window.
  • A hairline between commands, with each command's duration and a ✓ or ✕ with its exit code.
  • A row of key hints that lights up as you use them. Hide it once you know them.
  • A command palette (⌘K) with your recent commands. Picking one types it at the prompt; nothing runs until you press Enter.
Kerstel built in

Your secrets, one shortcut away

Press ⌘J (Ctrl+Shift+J on Linux) to open the Kerstel panel.

  • Secrets: filter, add, and delete. Values stay masked. Showing or copying one is recorded in kerstel audit, and a copied value is cleared from the clipboard after 30 seconds.
  • Sync: see the server, the last sync and your devices. Set up a server, join from another device, or add a device in a click. Each of these runs in the terminal, where Kerstel asks its usual questions. See Sync.
  • Doctor: check this machine's setup with one click.

The panel runs the same kerstel you use on the command line, so they always agree.

Build from source

Kerstel Terminal is open source, in apps/terminal. Its README has the build steps.
